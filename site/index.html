What the data taught me

SEC data is public, but it is not clean. Each of these was a real error in an early version, found while checking the output against the filings, and each fix has a test that keeps it from coming back.

  • PFIZERTwo concepts in one filing

    One 10-K tagged product sales with one XBRL concept and total revenue with another. Trying concepts in a fixed order picked the smaller one, so 2021 to 2023 revenue read $7.6B to $8.6B low.

    Now the most recently filed value wins for each year, and concept priority only breaks ties within the same filing.

  • KIMBERLY-CLARKRestatements distort growth

    A later filing restated 2023 for a divested business while 2022 stayed on the old basis. Comparing the two showed 2023 growth of −15.0%; like for like it was +1.3%.

    Growth is now measured inside the most recent single filing that reports both years.

  • JOHNSON & JOHNSONFiscal years ending in January

    Its 52- and 53-week years sometimes end on January 1, which the company labels as the prior year. Using the calendar year produced two fiscal 2023 rows.

    The label is now the year of the period end minus seven days, which still labels NVIDIA's year ending January 25, 2026 as fiscal 2026.

  • U.S. BANCORP · PNCGaps and missing tags

    A three-year gap in one bank's revenue tags misaligned the six-year window, and another bank reported no standard net income tag while the load still reported success.

    All metrics now share one year window, and a company missing a metric is flagged INCOMPLETE instead of counted as loaded.

The final check compares every stored figure with the value the SEC itself selected for that period, a mechanism the service never uses: 324 figures and 120 growth rates, 0 discrepancies.

Run it yourself

You need Docker. The SEC asks every client to identify itself, so set your name and email first.

git clone https://github.com/RJ318/peer-lens.git
cd peer-lens
cp .env.example .env      # set SEC_USER_AGENT="Your Name you@example.com"
docker compose up --build # dashboard on :8050, API on :8080
